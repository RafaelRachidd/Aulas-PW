### Atividade 02 — Escopo, user stories, wireframes e Kanban

**O que foi pedido:** pesquisar aplicações semelhantes ao tema escolhido, definir o escopo, elaborar três user stories, criar wireframes e organizar as tarefas em um quadro Kanban.

**O que foi feito:** em grupo, foi planejado um Sistema de Venda de Carros, com pesquisa de plataformas semelhantes, mapa do site, histórias de usuário, protótipos das telas e organização das tarefas no Trello.

**Integrantes:** Isabela Oliveira, Maria Luiza Oliveira, Veronica das Dores e Rafael Rachid.

### Atividade 07 — API de conversão de unidades

**O que foi pedido:** criar uma API com Express, publicá-la no Render e desenvolver uma interface que consuma a API.

**O que foi feito:** API de conversão de unidades de comprimento, utilizando o metro como referência e retornando resultados em JSON. A aplicação valida os parâmetros recebidos.

**Tecnologias:** Node.js, Express e Render.

| Método | Rota | Descrição |
|---|---|---|
| GET | `/unidades` | Lista as unidades disponíveis |
| GET | `/converter` | Realiza a conversão com os parâmetros valor, de e para |

| Item | Link |
|---|---|
| Repositório | [api_conversor_unidade](https://github.com/RafaelRachidd/api_conversor_unidade) |
| API no Render | [Unidades](https://api-conversor-unidade-1.onrender.com/unidades) |
| Exemplo | [Converter 100 metros em quilômetros](https://api-conversor-unidade-1.onrender.com/converter?valor=100&de=metro&para=quilometro) |

### Atividade 08 — CRUD de notas

**O que foi pedido:** desenvolver uma API CRUD de notas com Express, armazenar os registros em JSON, integrar um front-end e documentar a API no Postman.

**O que foi feito:** API de notas com as quatro operações CRUD e uma aplicação React denominada Minhas Notas. Na versão consultada do front-end, estão implementados o cadastro e a listagem de notas.

**Tecnologias:** Node.js, Express, JSON, React, Vite e Vercel.

| Método | Rota | Ação |
|---|---|---|
| GET | `/api/notes` | Listar notas |
| POST | `/api/notes` | Cadastrar nota |
| PUT | `/api/notes/:id` | Editar nota |
| DELETE | `/api/notes/:id` | Excluir nota |

| Item | Link |
|---|---|
| Back-end | [Aula_8_Notas](https://github.com/RafaelRachidd/Aula_8_Notas) |
| Front-end | [aula_8_front](https://github.com/RafaelRachidd/aula_8_front) |
| Site | [Minhas Notas](https://aula8front.vercel.app) |

### Atividade 09 — Website Builder com inteligência artificial

**O que foi pedido:** criar um site utilizando um Website Builder com IA, personalizar o design, desenvolver uma funcionalidade interativa e documentar o processo.

**O que foi feito:** desenvolvimento do **PRÁXIS**, plataforma educacional interativa sobre economia política e sociedade, com foco em conceitos da tradição marxista. O projeto foi criado com o Lovable, utilizando uma interface personalizada e recursos de aprendizagem por meio de textos, jogos e simulações.

| Funcionalidade | Descrição |
|---|---|
| Aprender | Módulos de estudo sobre economia política |
| Conceitos | Glossário de termos |
| Biblioteca | Área de referências e obras |
| Simulador da mais-valia | Representação didática do valor produzido, remuneração e excedente, com parâmetros ajustáveis |
| Jogo das classes | Identificação de posições nas relações de produção |
| Quiz | Questões de economia política com explicações |
| Sobreviva ao mês | Jogo de administração de um orçamento fictício |

**Ferramentas e tecnologias:** Lovable, React, TypeScript, TanStack Router e Vercel.
